# QtTranslateTool

用于将 Excel 词条导入到 Qt 语言家生成的 ts 文件中，也支持反向导出，并能自动整理尚未翻译的词条。

目前仅兼容 Windows 平台。

- Excel 导入到 Ts 支持覆盖 / 不覆盖
- Ts 导入到 Excel 支持覆盖 / 不覆盖

## 功能说明

### 文件载入

1. 选择或直接把 Excel（`.xls` / `.xlsx`）拖入窗口，进度条到达 100% 说明加载完成。
2. 选择或拖入一个或多个 Ts（`.ts`）文件，每个文件有独立的加载进度；可按住 Ctrl / Shift 多选。
3. 全部加载完成后，点击「填充 TS 文件」或「导出 Excel」完成转换。

支持拖拽到窗口任意位置，或拖到「输入文件」区域的虚线拖放区。

### 匹配项

- 可在右侧「匹配项」面板点击「保存当前匹配项」，把当前 Excel 与 TS 组合保存下来。
- 下拉选择匹配项即可一键重新载入对应的文件，适合反复处理同一批工程。
- 支持删除匹配项；下次启动时会自动恢复上次使用的匹配项与文件列表。

### 转换操作

- **Excel → TS**：按需勾选「覆盖已有译文」；未翻译的词条会提示选择保存路径，输出为单独的 xlsx 文件。
- **TS → Excel**：按需勾选「覆盖已有条目」，并可指定导出文件的保存路径。

## 构建

使用 Qt 5.14.2（MinGW 32 位或 MSVC 2017 32 位均可）：

```
qmake langImport.pro
nmake        # 或 mingw32-make
```

Release 构建的调试符号参数仅对 MSVC 生效，MinGW 下会自动跳过。
